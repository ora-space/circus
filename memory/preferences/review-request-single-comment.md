# 请求复审只发一条评论

请人复审时，只发**一条**评论说明 head、要点与逐条对应关系，默认发在运行单上；spec PR 需要面向公开读者时，更新 PR 描述即可，不另发评论。同一轮修复不要在运行单和 PR 上重复发，也不要为同一 head 追加多条催审评论。

复审人由用户去催：agent 发完这条评论后即认为球在 reviewer 手里，不主动重发或提醒。后续 head 推进时，只在原评论线程补充「head 已推进到 X」一条，或直接更新 PR 描述。
